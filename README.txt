YOUR PORTFOLIO WEBSITE
======================

FILES
- index.html : page content and sections
- style.css  : dark theme, layout and responsive design
- script.js  : mobile menu, scroll animations and footer year

HOW TO RUN IN VS CODE (WINDOWS)
1. Extract the ZIP file.
2. Open VS Code.
3. Select File > Open Folder.
4. Choose the extracted "madhumitha-portfolio" folder.
5. Open index.html.
6. If you have the Live Server extension, right-click index.html and choose
   "Open with Live Server". Otherwise, double-click index.html to open it
   in your browser.

PERSONALIZE BEFORE SHARING
1. In index.html, replace every "Your Name" with your preferred display name.
2. Replace your.email@example.com with your real email address.
3. Replace the sample LinkedIn and GitHub href="#" links with your profile URLs.
4. Replace "Arts & Science College" with your exact college name.
5. Add your GitHub repository URL to the EduGenie-AI project link.
6. Add a resume PDF and link it from a Resume button if you want one.

NOTES
- The portfolio is a static front-end website. It does not need Python, FastAPI,
  a database, or an API key to run.
- The EduGenie-AI project is described as a project showcase; this portfolio
  does not run the EduGenie application itself.
- Google Fonts uses an internet connection; fallback fonts are included.
